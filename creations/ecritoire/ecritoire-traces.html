Mise en page & export

Le mode Visuel est volontairement fluide, sur fond blanc, sans simulation de pages. Les tableaux larges y restent lisibles grâce au défilement horizontal. Le PDF est généré en texte natif/vectoriel : le texte reste sélectionnable, copiable et recherchable. Le réglage de qualité ci-dessus ne concerne désormais que les véritables images du document. Le PDF applique le format, l’orientation, les marges et peut réserver automatiquement des pages paysage aux tableaux trop larges. Imprimer reste disponible comme alternative native du navigateur si vous préférez la mise en page gérée directement par votre système.

Référencer un chemin / une URL

Idéal pour conserver un Markdown exploitable par d’autres outils : chemin relatif, URL distante ou URI file://.

Un chemin local absolu peut être conservé dans le Markdown même si certains navigateurs refusent de l’afficher pour des raisons de sécurité. Les chemins relatifs sont recommandés lorsqu’un dossier de documents accompagne le Markdown.

Image dans le document
