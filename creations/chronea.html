Bien démarrer avec Chronéa

Ajoute un repère avec une année seule, puis complète à ton rythme. Récit facilite la lecture ; Échelle montre les distances et durées ; Données permet l’édition groupée ; Relations donne les liens orientés.

Le cache du navigateur facilite le travail quotidien. Enregistre régulièrement un fichier .chronea ou un JSON complet : il transporte le projet et les médias. À l’import, « Restaurer » rouvre ce fichier ; « Ajouter » crée des chronologies indépendantes. Une fusion ne compare jamais les titres.

Tout reste local. Les liens distants ne sont ouverts que si tu les choisis. Les options de date complètent les mêmes bornes, sans formulaire concurrent. Publication produit une planche SVG/PNG et un dossier imprimable ; le JSON natif conserve les données éditables.
